# Garagem FZ25

App de manutenção da minha Yamaha Fazer FZ25 ABS, baseado no manual do proprietário: odômetro, plano de manutenção, checklists com histórico, pendências, combustível e relatório em PDF.

Instalável no celular (PWA) e sincronizado entre aparelhos pelo Firebase com login Google.

**Abrir o app:** https://hugomarcello.github.io/GaragemFZ25/
